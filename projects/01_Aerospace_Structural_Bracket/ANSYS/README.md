# ANSYS model files

Store manageable ANSYS Mechanical/Workbench project archives, solver inputs, or exported setup information here when practical.

Document the ANSYS version, analysis type, units, material assignment, mesh settings, loads, supports, contacts, and solver settings. Large project archives may be stored externally if they exceed GitHub's practical file limits; link to them here when appropriate.

Do not add solver files until the model exists.
