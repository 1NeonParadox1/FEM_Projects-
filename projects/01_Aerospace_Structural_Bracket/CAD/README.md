# CAD files

Store the bracket geometry used by this project here.

Suggested contents:
- Native CAD file (for example, SolidWorks `.SLDPRT` or `.SLDASM`)
- Neutral export (for example, `.STEP`) if useful for portability
- A short note describing dimensions, simplifications, and geometry revisions

Add these files when the geometry has been created. Avoid uploading unrelated or excessively large files.
